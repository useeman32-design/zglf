# IMPORTANT NOTE FOR GITHUB PAGES VISITORS
#
# GitHub Pages only serves STATIC files — it CANNOT run PHP or MySQL.
# That means https://useeman32-design.github.io/zglf/ will NOT serve the PHP
# backend (the admin panel, contact forms, donations, live data, etc.).
#
# To run this site with its full PHP+MySQL backend you need ONE of:
#   • XAMPP (recommended for local demo)  → see INSTALL_XAMPP.txt
#   • PHP built-in server                 → run START_LOCAL.bat (Windows)
#                                           or ./START_LOCAL.sh (Mac/Linux)
#   • cPanel / any PHP+MySQL web host     → see DEPLOYMENT.txt
#
# The static file index.html at the repo root is the public landing page
# and will load visually on GitHub Pages, but forms and admin will not work.
